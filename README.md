# Banking App UI

A mobile banking home screen, designed in Figma and built with React and Vite.

> Concept design, not affiliated with any brand. Logos belong to their respective owners.

- **Figma prototype:** _add your share link_

![Screenshot](screenshots/home.png)

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The `dist` folder can be hosted on GitHub Pages, Vercel or Netlify.

## Tech

React 18, Vite, plain CSS, Poppins (Google Fonts).
